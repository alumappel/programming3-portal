# אימות הפרונט והעורך המקומי

נבדק ב־21 באוקטובר 2026. כל 38 הבדיקות הממוכנות עברו, ובדיקת התחביר של JavaScript עברה. בדיקת ההפניות מחליפה את בדיקת הבנייה הישנה: היא מאמתת הפניות HTML, ייבוא מודולים, CSS וגופן ישירות מהקבצים הנערכים.

נבדק שקובץ התוכן המקומי נטען בלי פנייה ל־API, עם 35 קבוצות ותוכן במבנה תקין. נבדקה קריאת קובצי PDF סטטיים והיעדר קובצי backend, מסד נתונים, package.json ותיקיות build מתיקיית האתר.

בבדיקת HTTP, עם מסד נתונים זמני נפרד, התקבלו תגובות 200 עבור `index.html`, `admin.html`, ה־CSS, JavaScript, PNG וקובץ התוכן עם 35 קבוצות וחמישה שלבים. גישה לטיוטה ללא התחברות החזירה 401 ונתיבי מסד הנתונים הפרטי החזירו 404. הפעלת ייצוא התוכן הציבורי הושלמה בהצלחה. הנתונים הפרטיים שהועברו הושוו לעותק המקורי ונמצאו זהים.

נוספו חמש בדיקות לבחירת סיסמה פעם אחת, שמירת גיבוב בלבד, חסימת מקור זר וסיסמה קצרה, מניעת הגדרה חוזרת ובקשות מתחרות, ושמירת התוכן הציבורי הקודם אם ייצוא PDF נכשל.

בנוסף בוצעה בדיקת HTTP מול שירות מקומי אמיתי עם מסד נתונים ותיקיית ייצוא זמניים נפרדים: בחירת סיסמה, כניסה, טעינת 35 קבוצות, שמירת טיוטה ללא שינוי הקובץ הציבורי, פרסום ועדכון אוטומטי של הקובץ הציבורי. לאחר עצירה והפעלה מחדש נבדקו שמירת הסיסמה, התחברות חוזרת וביטול החיבור הקודם. השירות הזמני נעצר ונתוני הבדיקה הוסרו. לא הוגדרה סיסמה ולא פורסמו שינויים במסד הנתונים של הפרויקט לצורך הבדיקה.

נוספו שלוש בדיקות לרכיב הצגת התוכן באמצעות תחליף DOM קטן ב־Node, ללא דפדפן. הבדיקות משחזרות טופס אישי ללא הנחיות טקסט לקבוצה, שומרות על סינון לפי קבוצה, שלב ופרסום, ובודקות טופס קבוצתי ללא שיוך לשלב. לפני התיקון שלושתן נכשלו; לאחריו הן עברו. נבדק שהטופס נמצא בתוך מרחב הקבוצה, שההודעה על היעדר הנחיות אינה מופיעה לצדו, ושכפתור ההטמעה יוצר את המסגרת המתאימה. נבדקו גם קבוצה ללא תוכן ותצוגת טיוטה מקדימה.

לצורך אבחון תקלה קודמת נבדק מסד הנתונים של הפרויקט בקריאה בלבד: הטופס של קבוצה 3 היה משויך לשלב הראשון ומפורסם, והתוכן ב־API ובקובץ הציבורי היה זהה. תיקון הודעת היעדר התוכן שינה את הצגת התוכן בלבד.

בעדכון בלוקי הקבצים נוספו בדיקות לפיצול הנחיה ישנה בלי לאבד טקסט ושיוכים, לקבצים שהועלו בלי שיוך קודם, למחיקת קובץ בלי לפגוע בקבצים אחרים, ולהצגת PDF כתוכן יחיד לקבוצה בלי הודעה סותרת. נבדק גם שההערה על מספר הקבוצה ואישור השליחה אינה מופיעה ליד הטפסים. בדיקות השירות מאמתות שכל העלאה יוצרת בלוק קובץ יחיד שאינו מפורסם, שמחיקה מחייבת חיבור, CSRF וגרסת טיוטה עדכנית, ושפרסום מחיל את ההסרה בלי לשבור שחזור מההיסטוריה.

נבדק מיון הנחיות בעורך לפי מועד יצירה יורד, ללא תלות בערך סדר התצוגה לסטודנטים. נבדקו גם סדר יציב לתכנים ישנים, אי־שינוי מערך המקור ושמירת מועד היצירה בעת שמירת הטיוטה.

בדיקת HTTP נוספת מול שירות זמני בדקה העלאה, יצירת בלוק קובץ, פרסום וסנכרון PDF לנתונים הציבוריים, מחיקה מהטיוטה ללא השפעה מיידית על הפרסום, פרסום המחיקה ושחזור הקובץ לגרסת טיוטה. כל הפעולות בוצעו בנתוני בדיקה נפרדים. לפני עדכון השירות המקומי נוצר גיבוי SQLite עקבי בתיקיית `backend/.local/backups`; התכנים של הפרויקט לא נערכו ולא פורסמו לצורך הבדיקה.

לא הופעל דפדפן ולא נבדק תוסף Live Server באמצעות שליטת דפדפן. בדיקת השמירה והעדכון האוטומטי ב־VS Code, טופסי העורך, הנראות, המקלדת והמובייל מיועדת לביצוע ידני לפי [מדריך הבדיקות](../website/TESTING.md).
